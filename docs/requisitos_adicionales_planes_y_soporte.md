## 1. Variedad de Plantillas de Diseño (Inspiradas en Pinterest)

### 1.1. Filosofía de Diseño
Las nuevas plantillas toman como referencia visual las **tendencias estéticas de Pinterest** para fotografía y blogs de viajes internacionales, adaptadas al contexto turístico de Cusco y el Perú:
- **Fotografía protagonista:** Grids asimétricos, estilo Polaroid o Masonry layout.
- **Tipografías sofisticadas:** Fuentes serif elegantes para títulos (tipo revista de viajes) combinadas con sans-serif limpias para lectura rápida.
- **Paletas cromáticas curadas:** Tonos tierra, terracota, arena, lino andino, verde musgo y dorado solar, evitando colores planos o genéricos.
- **Micro-interacciones suaves:** Efectos sutiles al deslizar o pasar el cursor, dando sensación de catálogo de revista interactiva.

## 4. Sistema de Protección Anti-Spam

Para proteger el formulario de soporte y los formularios de cotización de envíos masivos o bots automáticos, se implementa una estrategia **multicapa**:

### 4.1. Medidas Anti-Spam Implementadas
1. **Técnica Honeypot (Campo Trampa Invisible):**
   - Se incluye un campo de formulario invisible para los humanos mediante CSS (`opacity: 0; position: absolute; pointer-events: none; tab-index: -1`).
   - Los bots rellenan todos los campos automáticamente. Si el backend/cliente detecta que ese campo tiene contenido, el envío se descarta silenciosamente.
2. **Validación por Tiempo Mínimo de Llenado (Time-Gate):**
   - Se registra la marca de tiempo (`timestamp`) cuando el usuario carga el formulario.
   - Si el formulario se envía en menos de 2.5 segundos (velocidad típica de un bot), se rechaza.
3. **CAPTCHA / Desafío Verificable:**
   - Para solicitudes críticas o sospechosas, un widget interactivo tipo reCAPTCHA / Cloudflare Turnstile o pregunta matemática simple (*"¿Cuánto es 4 + 3?"*).
4. **Rate Limiting (Control de Frecuencia):**
   - Límite de envíos por IP o navegador (máximo 3 consultas cada 10 minutos para evitar saturación del buzón).
