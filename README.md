# Cusco Creativos • Generador de Landing Pages para Turismo 🏔️

Plataforma especializada en la creación ultra-rápida de landing pages de alta conversión para agencias de viajes receptivas, operadores turísticos y guías oficiales colegiados de Cusco y Perú.

🌐 **Demo en vivo en Vercel:** [https://generador-de-landingpages.vercel.app](https://generador-de-landingpages.vercel.app)  
📦 **Repositorio Oficial:** [erikvlad1111-ctrl/Generador-de-Landingpages](https://github.com/erikvlad1111-ctrl/Generador-de-Landingpages)

---

## 🚀 Los 10 Puntos Clave del Generador Integrados

1. **Plantilla Visual:** 5 estilos disponibles (Portal Agencia Pinterest #1, Boho Travel Journal, Lujo VIP, Aventura & Trekking, Cultural & Ancestral).
2. **Fotografía de Portada (Hero):** Selección fotográfica en alta resolución, insignias flotantes y llamadas a la acción directas.
3. **Nivel de Servicio (Tiers):** Planes *Free*, *Basic*, *Pro* y *Advance* con renderizado dinámico según el perfil del cliente.
4. **Selector Multi-Idioma Dinámico (5 Idiomas):**
   - 🇵🇪 **Español (`es`)**
   - 🇺🇸 **Inglés (`en`)**
   - 🇧🇷 **Portugués (`pt`)**
   - 🇫🇷 **Francés (`fr`)**
   - 🇮🇹 **Italiano (`it`)**  
   *Al cambiar de idioma, toda la landing traduce sus textos, fichas, servicios e itinerarios al instante.*
5. **Objetivo Comercial & Enfoque de Conversión:** Ventas directas por WhatsApp, cotizador de grupos formal o enfoque híbrido dual.
6. **Ficha Técnica Oficial del Tour:** Altitud máxima, duración, dificultad física, modalidad de grupo, público objetivo y destino.
7. **Perfil del Guía & Servicios Incluidos:** Acreditación DIRCETUR oficial, idiomas dominados y bloque completo de servicios incluidos (transporte privado, tren panorámico, entradas oficiales, oxígeno a bordo y gastronomía).
8. **Itinerario Detallado:** Cronograma paso a paso (día a día u horarios) con tiempos optimizados para la aclimatación.
9. **Exclusiones Claras & Checklist de Mochila:** Transparencia total en lo que NO incluye y lista de equipaje recomendado.
10. **Distintivos Oficiales & Sellos de Confianza:** MINCETUR, DIRCETUR Cusco, Safe Travels, Agencia Formal RUC 20 y Balón de Oxígeno en ruta.

## 🛠️ Tecnologías Utilizadas

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS + Lucide React
- **Despliegue:** Vercel

---

## 💻 Ejecución en Entorno Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
